# Trait AipHandler

Trait for handlers that can be registered in the AIP registry.

Implementations are generated by the `#[aip_handler]` attribute macro. The trait carries metadata extracted from the function and provides a method to construct a `HandlerDefinition` that wraps the handler closure.

Note: The trait is not intended for manual implementation outside this crate at present. The macro-generated implementors live within this crate and access internal types directly.

## Trait Definition

```js
pub trait AipHandler {
    type Marker;
    type Params: AipParams;
    type Output: AipOutput;

    // Required method
    fn create_definition(path: &str) -> HandlerDefinition;

    // Provided method
    fn handler_meta() -> AipHandlerMeta { ... }
}
```

## Required Associated Types

- `type Marker` - Marker type indicating whether the handler is synchronous or asynchronous.
- `type Params: AipParams` - The typed parameters type.
- `type Output: AipOutput` - The typed output type.

## Required Methods

- `fn create_definition(path: &str) -> HandlerDefinition` - Construct a `HandlerDefinition` for the given path, wrapping the handler as a Lua closure and including all schemas and metadata.

## Provided Methods

- `fn handler_meta() -> AipHandlerMeta` - Returns the metadata (title and description) extracted from the handler’s doc comments. The default returns empty metadata; the `#[aip_handler]` macro overrides this to provide the actual values.

## Dyn Compatibility

This trait is **not** [dyn compatible](https://doc.rust-lang.org/1.97.1/reference/items/traits.html#dyn-compatibility).

*In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.*
